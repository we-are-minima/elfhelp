## Agent skills

### Issue tracker

Issues and specs live in local Markdown files under `.scratch/`. Before creating, reading, or updating tickets or specs, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before classifying an issue or changing its triage status, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase or updating domain documentation, read `docs/agents/domain.md`.
